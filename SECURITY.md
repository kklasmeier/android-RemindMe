# Security policy

## Supported versions

Only the latest `main` build is maintained. There is no Play Store channel yet; installs are debug APKs sideloaded with `adb`.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email the maintainer through GitHub: [kklasmeier](https://github.com/kklasmeier).

Include:

- A description of the issue and impact
- Steps or a proof of concept if you have one
- App version and Android version if it is device-specific

You should get an acknowledgement when the report is seen. There is no bug bounty.

## What this app stores

- Claude API keys live in `EncryptedSharedPreferences` on the device, never in git
- Reminder content is local Room data; `android:allowBackup` is false
- QR files generated by `tools/qr_generator.py` must stay off the remote (they are gitignored)

Do not commit `.jks` / `.keystore` files, `local.properties`, or real `sk-ant-` keys.
